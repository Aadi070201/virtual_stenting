# QCA gallery with vessel trees (P2, qualitative)

> **Research use only — not for clinical decisions.**

Generated by `vstent qca-gallery --tree`. Do not edit by hand.

The images and auto-selected paths of `reports/qca_gallery.md`. The side branches leaving the path are measured too (docs/PHYSICS.md, *Vessel trees*), and FFR comes from the tree solver. *Single path* is the main path alone with the single-vessel solver, the same value as the solver column in the single-path gallery. Lumen edges from the image intensity, guided by the segmentation (D43). Pixel size 0.30 mm/px assumed. There is no ground truth: this checks that the side-branch effect behaves plausibly. It is not a validation.

**What limits it.** The segmentation labels mark the major vessels only: ARCADE's SYNTAX segments and, in the rendered angiograms added in P8, vessels of at least 1.5 mm. Smaller side branches are unlabelled, so the segmenter rarely finds them and their flow stays in the main path. With the ARCADE-only M5 model, lowering the probability threshold did not help: on the first 10 images the skeleton had the same junctions at 0.5, 0.3 and 0.1. The automatic start point (the wider end of the longest path) is not always the ostium. When it is not, the vessel leading to the true inlet becomes a "side branch" and the flow direction is wrong (seen on val_107 with the M5 model). In the app and `vstent analyse` the user sets the start point.
