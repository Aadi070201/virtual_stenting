Generated by `vstent qca-gallery`. Do not edit by hand.

The first 20 `stenosis/val` images (by COCO id). For each one the longest path of the largest segmented vessel component is selected automatically, so it often is **not** the vessel with the annotated stenosis. Pixel size: 0.30 mm/px **assumed** (ARCADE has no calibration), so lengths, diameters and FFR are illustrative only. The model has no side branches: the full inflow is carried along the whole path, so long paths that taper into thin distal branches show large viscous pressure losses that real flow, which leaves through the branches, would not produce. Dashed orange boxes: ARCADE stenosis annotations. Lumen edges: from the image intensity, guided by the segmentation (the product default, D43).
