# Datasets

Source and licence of every dataset used by vstent. **No patient data is ever committed to this
repository.** All data lives under the git-ignored `data/` folder.

| Dataset | Source | Licence | Location | Used for | Status |
|---|---|---|---|---|---|
| Synthetic vessels v1 | generated by `vstent synth` (`configs/synth_v1.yaml`) | n/a (generated, no patient data) | `data/synth/v1/` | surrogate training / evaluation | generated (M2); see `reports/dataset_card.md` |
| ARCADE | Zenodo record 10390295, `arcade.zip` | *to be verified from the Zenodo page in M5* | `data/raw/arcade/` | vessel segmentation, stenosis evaluation | planned (M5) |

## Synthetic vessels v1

Regenerate with `uv run vstent synth --config configs/synth_v1.yaml` (add `--overwrite` to
replace an existing copy). Splits: train 100k (seed 1001), val 10k (1002), test 10k (1003),
ood 5k (1004; 80–120 mm, 3–4 lesions). The data folder holds the shards, `manifest.json`
(array units, per-shard content hashes), the resolved `config.yaml` and `run_meta.yaml`
(git commit). Statistics: `reports/dataset_card.md`.
